# MOVICI Website — Complete V1

This is a ready-to-open RStudio + Quarto website project.

## Open and preview

1. Install Quarto.
2. Open `MOVICI_Website.Rproj` in RStudio.
3. Open `index.qmd`.
4. Use **Render / Preview**, or run `quarto preview` in the RStudio Terminal.

## Website structure

- Home
- WP01 — CAVL
- WP02 — Information Search
- WP03 — Debate
- WP04 — Information Search & Debate
- WP05 — Agent-Based Model
- Project Team
- Funding

## Content integrated

- Full English text of all five MOVICI working papers
- MOVICI Research Programme as the collective site author
- Five embedded YouTube video presentations
- MOVICI YouTube playlist on the homepage
- PDF download for every working paper
- Data & replication package download for WP02–WP05
- Figures and tables from the manuscripts
- Full reference lists
- Citation hover helper: hovering over recognized in-text references shows the full reference; DOI links can be opened from the tooltip where a DOI is available
- Project Team
- Funding

## Editorial choices

As requested, the website article pages do **not** repeat manuscript declarations, individual author placeholders, funding, author-contribution statements, acknowledgements, or AI-use statements. Funding is centralized on the Funding page, while project contributors are centralized on the Project Team page.

CAVL is theoretical and therefore has no empirical replication package.

The PDF downloads are generated from the final supplied manuscripts with only the displayed author placeholder normalized from `Authors to be confirmed` to `MOVICI Research Programme`.

## V1.1 DOI behaviour

- In-text citations recognized by the MOVICI citation system remain hoverable.
- When the cited reference has a DOI, the in-text citation itself is clickable and opens the DOI in a new tab.
- DOI URLs in the bibliography are explicit clickable links.
